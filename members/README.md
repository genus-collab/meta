# Membership register

Three tiers (charter § Governance):

- **Public contributors** — write access to thematic repos on request to the Strand Lead.
- **Community members** — register by PR adding a line to `community.csv` with a verified
  institutional affiliation; an SC member seconds the PR by approving it.
- **Core members** — nominated by the SC; recorded in `core.csv`.

Do not record personal email addresses here; use GitHub handles.
